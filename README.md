# 정제된 악

**해킹 · 파괴의 예술 · 정제된 악**

이 문서는 ‘정제된 악’이라는 개념을 중심으로,  
해킹과 파괴가 단순한 기술이 아니라 **미학적이고 고도화된 형태**로 나타날 때 생기는 본질을 다룬다.

조잡한 악은 눈에 잘 띈다.  
정제된 악은 그렇지 않다.  
그것은 감정과 충동을 걸러내고, 의도·계획·미학만을 남긴 상태다.

해킹이 파괴의 예술이 되는 순간,  
그리고 그 예술이 정제된 악의 형태를 띨 때,  
우리는 선과 악의 경계가 기술적으로는 명확하지만 심리적으로는 흐려지는 지점을 마주하게 된다.

이 문서는 그 지점을 탐구한다.
